# Weaver Games privacy policy

The privacy policy for every game Weaver Games publishes, served by GitHub
Pages at **https://weavergamesstudio.github.io/privacy/**. Store listings on
Google Play and the App Store link to that address, so it must never move.

- `index.html` is the whole policy: plain HTML with no scripts, fonts or
  trackers, readable on a phone, in light and dark mode.
- Each game has its own section (`#shard-horizon`, ...). Adding a game means
  adding a section, and updating the date at the top.
- A game's data practices change **before** the update that changes them
  ships: edit its section and the date, then check the store forms (Google's
  Data safety, Apple's App Privacy) still agree.

Changes go through pull requests. Contact: weavergamesstudio@pm.me.
